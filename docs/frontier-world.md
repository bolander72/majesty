can temporarily retain up to 98 resident regions (100,352 terrain bytes).
View bounds are capped at 2048
world units per axis; canvas backing dimensions are capped at 4096 per axis.

render loop. Tile drawing clips partial regions to the actual visible tiles.

a visible error rather than pretending that the save succeeded.
