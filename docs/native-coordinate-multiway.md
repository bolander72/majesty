The original native engine now follows a six-visit route through committed
`0_0`, the independently generated and initialized `0_1`, and committed `1_0`.
Coordinate requests select each destination's actual saved file; the controller
does not substitute alternating copies of the same kingdom.

This uses exact archived native102, with no new build or C++ changes. It is an
owned native prototype, disabled under Emscripten. The served WASM is unchanged.
Browser/co-op activation, natural actor crossing, arbitrary region creation,
full campaigns/matches, independent internet gameplay and sustained resource
bounds remain unfinished requirements of the active goal.
