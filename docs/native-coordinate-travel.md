# Native coordinate-based region activation

The subsequent [native102 multi-way trial](native-coordinate-multiway.md)
qualifies coordinate activation of a third independently generated kingdom.
The native099 evidence below retains its original two-kingdom scope.

Native099 adds coordinate routing to the original save/unload/restore fixture.
The controller chooses a neighboring saved region, rather than accepting only
a predetermined next side. Canonical coordinate filenames select and publish
the dormant kingdoms. The native state retains current and pending XY pairs;
it does not retain a catalogue of every explored region or load a destination
before disposing the current world's six tracked roots.

This is an owned, opt-in native prototype. It is disabled under Emscripten and
does not change the served WASM. The actual trial still uses the two committed
registered-hero kingdoms. Other saved destinations, fresh generation, spatial
hero crossing and browser/cooperative activation remain unqualified.

## Request and publication

`BROWSER_STREAMING_REGION_REQUEST_FIXTURE=v2` retains the existing isolated
automatic-load and registered-hero fixture requirements. Ready/request records
have exactly nine little-endian DWORDs (36 bytes):

| Word | Meaning |
| ---: | --- |
| 0 | Magic `32565254` (`TRV2`) |
| 1 | Version 2 |
| 2 | Current load serial |
| 3, 4 | Current signed region X, Y |
| 5, 6 | Requested signed destination X, Y |
| 7 | Current region's initial saved clock |
| 8 | Operation: ready 0, travel 1, final fixture stop 2 |

Readiness names the current region in both XY pairs. The controller fills the
destination and travel operation. The final readiness permits only a stop at
the current region. Serial, acceptance counter, source, initial clock, operation,
exact length/EOF, coordinate bounds and cardinal adjacency are checked at a
completed original tick. Polling remains at most every 200 ms. Cheap packet
checks precede destination lookup. Coordinates are limited to ±1,000,000;
missing neighbors are refused rather than generated silently.

Destinations are owned `Residency_Region_<x>_<y>.GMP` files. Admission checks
their size (272 bytes through the existing 2 MiB fixture limit) and original
VERS header. This is not full asset/content or checkpoint validation. The runner
supplies independently verified original files; original restoration and stopped
full-state comparison qualify the admitted files used in this trial. General
untrusted imports and a full content-aware destination manifest remain separate
work. The browser's independent region backups have their own validation path.

An accepted request records a pending destination. The current region stays
selected while its original full save publishes under its coordinate filename.
Only after original disposal and six-root retirement does the adapter copy the
destination into the original named loader's input and change its current XY.
Normal interface rebuilding, saved RNG restoration and subsequent original ticks
remain. Legacy side diagnostics still appear in the reused lifecycle trace;
the additional coordinate snapshots/activations bind actual filenames and keys.

## Actual trial and correction

refuses it: a later replay packet matches an earlier malformed packet's words,
so cross-visit log deduplication suppresses that refusal. Preserve that actual
log, failed inspection, build report and pre-correction source. Native099 resets
refusal observation at each new readiness. Attempt002 exposes all five actual
refusals: stale serial, missing `0_1`, non-neighbor `2_0`, a trailing byte and
replay of the first accepted request in `1_0`. All refuse while gameplay continues.

The corrected route is `0_0 → 1_0 → 0_0 → 1_0`, followed by a distinct final stop.
Its visits complete 34/46/35/50 original ticks, 165 in total. Every initial/warm
compared saved state, queue, entity, attachment and both RNGs restores under the
existing audited metadata/shading/ORDR rules. Warrior504/GPL28 remains inside
guild469/GPL7 with its original rest context and unique ownership; removed remote
554/GPL48/effect555 remain absent and pure45 stays inert. No hero is transferred.

Four post-cleanup original saves preserve compared gameplay, raw terrain and
