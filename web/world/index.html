About this experiment

This tests bounded map storage and rendering using simple generated terrain. In a named world, you can also view saved Majesty terrain as an altitude map with building squares and smaller unit markers colored by kingdom. It shows the last save; units inside buildings are omitted and crowded areas have limited markers. Empty areas have no checkpoint. A region opens a separate native Majesty kingdom and resumes its checkpoint when available. The game's Frontier controls can save and travel north, south, east or west, or return to this map at the current region. Heroes do not yet cross region boundaries. Unloaded regions remain dormant.
